# Api Time Machine

Chrome extension + local server that records XHR/fetch traffic and replays any past app state

![Language](https://img.shields.io/badge/language-TypeScript-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![GitHub](https://img.shields.io/github/stars/Ap-0007/api-time-machine?style=social)

## 📖 About

Chrome extension + local server that records XHR/fetch traffic and replays any past app state

## 🛠️ Tech Stack

- **Primary Language:** TypeScript

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Ap-0007/api-time-machine.git
cd api-time-machine
```

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
